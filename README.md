# otechai

Personal blog at [otechai.github.io](https://otechai.github.io).

## What this is

Notes on building small, useful things — CLI tools, static sites, and
open-source utilities that solve a real annoyance without needing a backend,
an account, or a subscription. Most posts come out of actually building
something: what worked, what broke, and what I'd do differently.

Recurring interests:

- Free and open-source tooling (GPL-licensed by default)
- Terminal workflows and small scripts worth sharing
- Static, no-backend sites that do one job well
- Civic and transparency-minded tools built on public data

## Status

Just getting started — the site currently shows a "coming soon" page.
Posts go up as they're written, not on a schedule.
